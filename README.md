# Course Test automation in java Aston

### Урок 15. Практическое задание.
1. Написать автотесты для сайта wildberries.ru, в ходе которых 
на главной странице несколько товаров кладется в корзину, 
затем осуществляется переход в корзину
   1. и происходят проверки на соответствие названия товаров, 
   2. их количество, 
   3. цен каждого товара в корзине 
   4. и общей суммы товаров.
2. При написании автотестов необходимо использовать подходящие паттерны, изученные в данной теме.
